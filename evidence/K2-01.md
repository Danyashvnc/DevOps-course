Посмотрел образ devops-course:base и контейнеры из него, остановил web, потом запустил обратно и отправил заявку.

```
docker image inspect devops-course:base
Id: sha256:cfe6e24a31c7...
RepoTags: [devops-course:base]
Os/Arch: linux/amd64
User: 10001:10001
WorkingDir: /app
Cmd: [python app.py]
ExposedPorts: 8000/tcp

docker image ls devops-course
devops-course   base   cfe6e24a31c7   181MB
```

Образ на linux, приложение запускается командой python app.py из /app от пользователя 10001, внутри слушает 8000.

```
docker compose ps
NAME                  IMAGE                SERVICE   STATUS          PORTS
devops-course-api-1   devops-course:base   api       Up (healthy)    8000/tcp
devops-course-web-1   devops-course:base   web       Up (healthy)    127.0.0.1:8080->8000/tcp
```

Два контейнера из одного образа. Роль им задаёт переменная ROLE из compose.yaml. У api ROLE=api и DATA_DIR=/data, он пишет заявки в базу. У web ROLE=web и API_URL=http://api:8000, он отдаёт страницу и пересылает запросы в api. На компьютер проброшен только web, порт 8080.

Остановил web:

```
docker compose stop web
docker compose ps -a
api   Up (healthy)    8000/tcp
web   Exited (137)

curl -i http://localhost:8080/
curl: (7) Failed to connect to localhost port 8080
```

Страница вообще не грузится. api живой, но я до него из браузера не достаю, у него нет порта наружу. Образ при этом никуда не делся, docker image ls его показывает.

Запустил обратно:

```
docker compose start web
web   Up (healthy)   127.0.0.1:8080->8000/tcp

curl http://localhost:8080/  -> 200

POST /api/requests {"kind":"software"}
HTTP/1.0 201 Created
{"request": {"id": 4, "kind": "software", ...}}
```

В логе api появилось request_accepted request_id 4, в логе web POST /api/requests 201. Номер 4, старые 1-3 на месте: я останавливал только web, а заявки лежат у api в томе. Пересобирать ничего не пришлось, start поднял тот же контейнер.

Вопрос: удаляется ли образ, когда останавливаешь web?
Нет. stop действует на контейнер. Образ лежит отдельно, из него можно сделать ещё контейнеры, и удалить его можно только через docker image rm.
