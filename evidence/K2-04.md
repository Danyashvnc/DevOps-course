```

docker pull localhost:5000/workshop:v1
```

Слои заново не скачались, у меня они уже были от devops-student:v1.

Ещё открыл http://localhost:5000/v2/workshop/tags/list, там {"name":"workshop","tags":["v1"]}.

digest: sha256:f02acb7b195465678c847fece2120f80a3def2188321120068ec89a8ee9b83aa
У push и pull он совпал, значит скачал то же что отправил. Метка course.student тоже на месте.

tag и digest. Тег v1 это имя, его можно перевесить: пересобрать образ и снова запушить как v1, и под тем же тегом будет другой образ. digest docker считает по содержимому, поменяй в образе хоть что-то и digest станет другой. Поэтому по digest можно точно сказать какая версия, по тегу нельзя.

Вопрос: почему после push приложение не запускается?
push только кладёт образ в хранилище. Чтобы оно заработало, кто-то на нужной машине должен сделать pull и docker run или compose up. Сам registry ничего не запускает.
